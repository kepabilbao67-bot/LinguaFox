# Cuestionario de Clasificación de Contenido (IARC) — LinguaFox

Respuestas orientativas para cumplimentar el cuestionario de la **Coalición Internacional de Calificación por Edad (IARC)** en Google Play Console para LinguaFox.

---

## 1. Categoría de la Aplicación
- **Categoría principal elegida:** Aplicación de referencia, noticias, educación o utilidad general (*Educación*).

---

## 2. Respuestas al Cuestionario de IARC

| Pregunta / Sección | Respuesta | Justificación Técnica |
| :--- | :---: | :--- |
| **Violencia** | **NO** | No contiene escenas de violencia, sangre, combate ni armas. |
| **Miedo / Terror** | **NO** | No incluye elementos diseñados para asustar ni contenido de terror. |
| **Sexualidad / Desnudez** | **NO** | Cero contenido sexual, referencias eróticas o desnudez. |
| **Lenguaje soez / Ofensivo** | **NO** | Vocabulario educativo estándar y familiar en inglés y español. |
| **Sustancias controladas** | **NO** | No hace referencia al consumo de tabaco, alcohol, drogas ni sustancias ilegales. |
| **Juegos de azar / Apuestas** | **NO** | No incluye apuestas con dinero real ni simulaciones de casinos. |
| **Contenido generado por usuarios** | **NO** | No hay foros, comentarios públicos ni intercambio de mensajes entre usuarios. El tutor y los personajes son locales. |
| **Intercambio de ubicación física** | **NO** | La aplicación no solicita ubicación ni permite compartirla. |
| **Compras de bienes digitales** | **NO** | No contiene compras dentro de la aplicación (*in-app purchases*). |
| **Navegador web integrado libre** | **NO** | No incluye un navegador web que permita navegar sin restricciones por Internet. |

---

## 3. Calificación por Edad Prevista (Estimación Sujeta a IARC)

> [!NOTE]
> La siguiente clasificación es una **ESTIMACIÓN ORIENTATIVA SUJETA A LA VALIDACIÓN OFICIAL DEL CUESTIONARIO IARC** al ser completado en Google Play Console.

Tras responder a los ítems técnicos anteriores, las calificaciones estimadas resultantes de IARC son:

- **PEGI:** PEGI 3 (Estimación orientativa / Apta para todos los públicos).
- **ESRB:** Everyone (E) (Estimación orientativa).
- **USK:** USK 0 (Estimación orientativa).
- **Google Play:** Apto para todo público / Para toda la familia (Estimación sujeta a revisión).
